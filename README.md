# فاحص (Fahes)

**افحص أهليتك قبل أن تودع الملف.**

فاحص أداة مجانية تجمع الشروط الرسمية للخدمات العمومية الجزائرية وتحوّلها إلى فحص أهلية حسابي دقيق،
ثم توجّه المستعمل إلى الموقع الرسمي للإيداع. **بلا ذكاء اصطناعي**: كل شرط قاعدة مكتوبة قابلة للتدقيق.

## المحرّك
القواعد مكتوبة بلغة [Publicodes](https://publi.codes/) مفتوحة المصدر (نفس التقنية التي تستعملها
الإدارة الفرنسية لحساب أهلية المساعدات). كل خدمة = ملف YAML واحد في `src/rules/`:
الأسئلة (`question`)، الشروط (`cond . *` مع `titre` و`description`)، والمبالغ المحسوبة (`montant . *`).
تغيّر مرسوم؟ تعدّل سطراً في YAML بلا برمجة.

## الخدمات (24 + وحدة التأشيرات)
- **السكن**: عدل 3، السكن العمومي الإيجاري، الترقوي المدعم LPA، إعانة السكن الريفي، قرض CNEP
- **العمل والمقاولاتية**: منحة البطالة، ANADE، CNAC، ANGEM، المقاول الذاتي ANAE، التقاعد CNR
- **المنح والحماية الاجتماعية**: AFS، الإعاقة، المنحة المدرسية، المنحة الجامعية، بطاقة الشفاء للطالب
- **المشاريع والاستثمار**: اللابل (startup.dz)، تمويل ASF، امتيازات AAPI، بطاقة الفلاح والقرض الفلاحي
- **الحياة اليومية**: التكوين المهني، قرعة الحج، مرابحة سيارة، دعم السخان الشمسي
- **التأشيرات**: فحص ملف شنغن (مبالغ المفوضية الأوروبية، قاعدة 90/180) + 193 دولة + أسباب الرفض الرسمية

## التشغيل
```bash
npm install
npm start        # PORT=3070 افتراضياً
```

## البنية
```
src/rules/*.yaml   قواعد Publicodes (شرط واحد = قاعدة واحدة بشرح عربي)
src/engine.js      تحميل القواعد وتقييمها (pass / fail / unknown)
src/services.js    بطاقات الخدمات: الجهة، الرابط، الوثائق، المصادر
src/routes/visa.js وحدة التأشيرات
src/views.js       نظام التصميم (RTL، أحمر متدرّج، مبني للهاتف أولاً)
src/server.js      Express
```

## مبادئ
لا نقبل ملفات، لا نبيع مواعيد، لا نضمن نتيجة، ولا نخزّن أي بيانات مستعمل.
المرجع النهائي دائماً هو النص الرسمي وموقع الجهة المعنية.

مرجع محيّن: SNMG = 24.000 دج منذ 01 جانفي 2026 (مرسوم رئاسي 26-01).
