# فاحص (Fahes)

**افحص أهليتك قبل أن تودع الملف.**

فاحص أداة مجانية تجمع الشروط الرسمية للخدمات العمومية الجزائرية وتحوّلها إلى فحص أهلية حسابي دقيق،
ثم توجّه المستعمل إلى الموقع الرسمي للإيداع. **بلا ذكاء اصطناعي**: كل شرط قاعدة مبرمَجة قابلة للتدقيق.

## الخدمات المغطّاة (14)
- **السكن**: عدل 3، السكن العمومي الإيجاري، الترقوي المدعم LPA، إعانة السكن الريفي، قرض CNEP
- **العمل والمقاولاتية**: منحة البطالة، ANADE، CNAC، ANGEM، التقاعد CNR
- **المنح**: المنحة الجزافية للتضامن AFS، بطاقة/منحة الإعاقة، المنحة المدرسية الخاصة، المنحة الجامعية
- **السفر**: يحيل إلى مشروع «ملفّي» (فاحص ملف التأشيرة)

## التشغيل
```bash
npm install
npm start        # PORT=3070 افتراضياً
```

## البنية
- `src/data/*.js` — الخدمات: الحقول، القواعد، الوثائق، المصادر الرسمية
- `src/engine.js` — محرّك الفحص (pass / fail / unknown)
- `src/views.js` — التصميم (RTL، ثيم أحمر متدرّج)
- `src/server.js` — Express: الصفحات والاستمارات والنتائج

## مبادئ
لا نقبل ملفات، لا نبيع مواعيد، لا نضمن نتيجة، ولا نخزّن أي بيانات مستعمل.
المرجع النهائي دائماً هو النص الرسمي وموقع الجهة المعنية.

مرجع محيّن: SNMG = 24.000 دج منذ 01 جانفي 2026 (مرسوم رئاسي 26-01).
